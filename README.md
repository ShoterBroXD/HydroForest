# HydroForest
HydroForest es un sistema de clasificación de calidad de agua mediante Random Forest, implementado en Go con goroutines para paralelizar el entrenamiento sobre un dataset de más de 2.8 millones de registros históricos (1940-2023). Proyecto del curso CC65 (Programación Concurrente y Distribuida), alineado con el ODS 6: Agua Limpia y Saneamiento.
