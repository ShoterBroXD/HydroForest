# Dataset

## A Comprehensive Surface Water Quality Monitoring Dataset (1940-2023)

**Autores:** Karim, M. R.; Syeed, M.; Rahman, A.; Rabbani, K. A.; Fatema, K.; Khan, R. H.; Hossain, M. S.; Uddin, M. F. (2025)
**Fuente:** figshare
**DOI:** https://doi.org/10.6084/m9.figshare.27800394.v2
**Licencia:** Creative Commons Attribution 4.0 International (CC BY 4.0)

## Descripción

- **Registros:** 2.82 millones
- **Cobertura temporal:** 1940-2023
- **Países/regiones:** Estados Unidos, Canadá, Irlanda, Inglaterra, China
- **Formato:** CSV (304 MB)

## Columnas

| Columna | Descripción |
|---|---|
| Country | País/región del cuerpo de agua |
| Area | Zona específica dentro de la región |
| Waterbody Type | Tipo de cuerpo de agua (río, lago, etc.) |
| Date | Fecha de muestreo|
| Ammonia (mg/l) | Concentración de amonio |
| Biochemical Oxygen Demand (BOD) (mg/l) | Demanda bioquímica de oxígeno |
| Dissolved Oxygen (DO) (mg/l) | Oxígeno disuelto |
| Orthophosphate (mg/l) | Concentración de ortofosfato |
| pH (pH units) | Nivel de pH |
| Temperature (cel) | Temperatura del agua |
| Nitrogen (mg/l) | Concentración de nitrógeno |
| Nitrate (mg/l) | Concentración de nitrato |
| CCME_Values | Índice numérico de calidad de agua (CCME WQI) |
| CCME_WQI | Clasificación de calidad de agua (Excellent, Good, Fair, Marginal, Poor). **Variable objetivo del modelo.** |


## Cómo descargarlo

1. Descargar el CSV desde: https://figshare.com/articles/dataset/A_Comprehensive_Surface_Water_Quality_Monitoring_Dataset_1940-2023_2_82Million_Record_Resource_for_Empirical_and_ML-Based_Research/27800394
2. Colocarlo en la misma carpeta que el notebook con el nombre `water_quality.csv`.
